| Evidence class | What the artefact is |
| Produced by | Which controls produce it, and at what cadence |
| Store | Where it lives, and how it is reached |
| Retention | How long, and under which retention rule |
| **Sampling unit** | **What one occurrence looks like.** This is what the auditor asks for after asking for the population, and a class without it cannot be sampled |
| Population per period | How many units a six-month period produces |
| Completeness | How anybody can tell the population is complete — the control that generates it, the system that records it, the reconciliation that proves none is missing |
| Integrity | What stops a unit being altered after the fact |
| Access | Who can retrieve it, and how an auditor is given access |

**Four fields, and the fourth is the one ML-1 was about.** The 2025 Type I management letter recorded
access review evidence retained as email threads and screenshots. It was retained. It was complete. It had
no sampling unit — no answer to "show me the review for this system for this quarter" that did not involve
somebody reconstructing it from a mailbox.

**On completeness.** A sampler drawing from a population needs to know the population is the whole
population. An evidence class assembled by somebody searching for the artefacts is a class whose
completeness rests on the diligence of the search, and that is not a control.
